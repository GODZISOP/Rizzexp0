# RizzExp0 — Haute Horlogerie

A luxury interactive watch showcase and product experience built with pure HTML, CSS, JavaScript, and Matter.js.

## Features
- **Interactive 4-Watch Hero Showcase:** 60fps GPU side-slide transitions with dynamic theme color sync across *Sovereign Espresso*, *Aether Midnight*, *Verdant Royal*, and *Obsidian Chrono*.
- **Double Stairs Reveal Transition:** Dual-direction synchronized staircase reveal leading into the editorial watch anatomy section.
- **Scroll-Linked Editorial Choreography:** Watch scale-up entrance, sequential anatomy callout lines, Word Pull Up headlines, scroll-linked grey-to-black reading fill, and continuous watch scroll travel from Block 01 into Block 02.
- **Oliver Parallax 4-Column Gallery:** Multi-speed vertical parallax horology archive with bespoke macro and editorial photography.
- **Dedicated Product Detail Page (`product.html`):** Watch-specific multi-angle galleries, edition swatches, quantity selector, favorites, technical specifications, and persistent `localStorage` shopping bag drawer.
- **Animated FAQs & Private Concierge Contact:** Smooth accordion FAQs, inquiry form, and direct concierge contact (`info@rizzexp0.com`).
- **Interactive Gravity Blocks Footer:** Multi-column luxury footer with Matter.js zero-shake rigid-body falling & throwable pills.
- **Fully Responsive:** Mobile drawer navigation and tuned layouts across desktop, tablet, and mobile viewports.

## Run Locally
```bash
python -m http.server 8080
```
Then open `http://localhost:8080` in your browser (or deploy directly with GitHub Pages).
